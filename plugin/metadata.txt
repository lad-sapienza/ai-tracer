about=AITracer by LAD brings AI-assisted raster digitization to QGIS 4.

    Activate the tool, click any feature in a georeferenced raster —
    aerial photo, drone orthophoto, scanned plan — and the SAM2-tiny
    model segments it instantly as a polygon preview. Refine the result
    with positive or negative point prompts, adjust Douglas-Peucker
    simplification, then accept to add the polygon to any vector layer.

    HOW IT WORKS: AITracer captures a screenshot of the current QGIS
    canvas and sends it to SAM2 — it does not read the original raster
    file. This keeps processing fast and memory-light on modest hardware.
    The output resolution depends on your zoom level, not the raster
    resolution. Features that extend beyond the canvas edge will be
    partially traced. The canvas is locked during a session to keep
    pixel-to-map coordinates consistent.

    First-time setup automatically downloads a standalone Python runtime
    and the SAM2-tiny model weights (~160 MB). An internet connection is
    required for this one-time step only. All subsequent processing runs
    entirely on your machine; no data is ever sent to external servers.

    Developed by LAD — Laboratorio di Archeologia Digitale,
    Sapienza University of Rome.
changelog=0.4.0
    - New: "Snap to neighbours" option. The new polygon shares its boundary with
      polygons already in the output layer: overlaps are cut, small gaps are
      closed, and the outline follows one coherent perimeter across several
      neighbours (like QGIS's tracing tool). Matching vertices are added to the
      neighbours without changing their shape, so the layer stays topologically
      valid. Snap distance is set in screen pixels; the choice is remembered.
      One undo reverts the new polygon and the vertices added to neighbours.
    - Fix: deprecated QgsEditorWidgetWrapper.setValue() replaced by setValues().
    0.3.0
    - New: model selector in the panel. Choose between SAM2.1 Tiny (default,
      156 MB), Base+ (324 MB) and Large (898 MB, ~3 GB RAM). Models are
      downloaded on demand after confirmation, and the backend switches model
      without restarting. The choice is remembered across sessions.
    - New: model downloads are streamed to disk with real progress and a working
      Cancel button (flat memory use even for the Large checkpoint).
    - New: simplification tolerance is now expressed in screen pixels (0-6 px,
      default 2.8 px), so its effect no longer depends on zoom level or CRS.
      Finer steps, live vertex count, value remembered across sessions.
    - Improved: refining a mask reuses the previous mask as input, so successive
      clicks change the result far less (more stable masks).
    - New: "E" keyboard shortcut for "Edit last polygon".
    0.2.2
    - Fix: Qt6 compatibility, fully qualified QgsBlockingNetworkRequest.ErrorCode.NoError.
    0.2.1
    - Fix: address static-analysis (Bandit) findings: no silent exception
      swallowing, subprocess calls documented and restricted to fixed paths.
    0.2.0
    - First stable release (experimental flag removed).
    - New: Pause/Resume. Switching to another QGIS map tool (e.g. Vertex tool)
      pauses AITracer and discards the in-progress preview; press Resume in the
      panel to continue. Backend, target layer and field values are kept.
    - New: "Edit last polygon" button. Selects the last accepted polygon and
      switches to QGIS's native Vertex tool; the selection is cleared on Resume.
    0.1.33
    - Field values panel: preset attributes for accepted polygons.
    0.1.32
    - Model weights stored in ~/.aitracer/weights/, surviving plugin reinstalls.
